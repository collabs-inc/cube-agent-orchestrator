# Cube port implementation plan

> Execute inline using superpowers:executing-plans, with a final independent review.

**Goal:** Run the upstream agent workspace on Cube with real machine resources.

**Architecture:** A loopback Node launcher supervises the Go daemon, serves the
renderer, and proxies same-origin API/stream traffic. An opt-in Cube renderer
adapter implements essential desktop bridge behavior without preview data.

**Tech stack:** Go daemon, Node HTTP server, React/Vite renderer, Cube manifest.

**Spec:** `docs/superpowers/specs/2026-10-10-cube-port-design.md`

## Constraints and review focus

Preserve Electron behavior, upstream licenses, and all real user state. Test
cross-origin mutation rejection, proxy stream/upgrade handling, daemon startup
failure, filesystem path validation, and shutdown of owned children only.

## Tasks

- [x] Add launcher tests in `cube/server.test.mjs` for readiness, static serving,

  Implement `cube/server.mjs` and `cube/start.mjs`; verify and commit.
- [x] Add browser adapter tests for real daemon readiness and same-origin API

- [x] Add reproducible `cube/install.mjs` and root `cube.json`; build daemon and
  renderer with pinned toolchains, store state outside install directory.
  Document install/update/runtime behavior and attribution.
- [x] Run isolated browser acceptance with a temporary Git repository, a real
  daemon and terminal, and a controlled worker command. Run upstream validation
  suites where supported, record failures and unavailable platform jobs.
- [x] Request independent review, resolve findings, commit, push, and open PR.

## Verification record

A clean rootless installation completed and started with its bundled Node,
served the renderer, reported its own daemon ready, and shut down cleanly.
The port passes its gateway/filesystem tests, browser adapter and terminal
regressions, renderer build, and production renderer typecheck. An isolated
browser run verified machine folder selection, repository registration, a
worktree worker, terminal input/output, and reload. A launcher restart retained
the project and session; shutdown stopped only its owned daemon. The fixture's
workers were explicitly terminated afterward.

The broader local upstream suite was stopped after environment failures:
macOS update and blockmap fixtures need the absent `zip` executable. An initial
Electron import failure passed on rerun after downloading the test-only Electron
binary. The full upstream suite is not claimed green. GitHub Actions runs the
upstream and Cube checks on the PR. Real provider sign-in and production Cube
HTTPS/WSS routing remain integration checks.

Independent review findings were resolved, including the root static route,
filesystem scanner home protection, browser profile mutation errors, the
terminal's Electron-only preview guard, and CI path coverage.
